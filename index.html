公開同步的權限與注意事項

免登入的代價是：任何知道網址、且能連到此資料路徑的人，都可能讀取或改寫共享看板。不要在裡面放密碼、個人證件資料或其他敏感資訊。這個規則只針對 studyProgressPublic/sharedBoard；請把規則加進既有規則，不要直接覆蓋整份 Firestore Rules。

match /studyProgressPublic/{docId} {
  allow get: if docId == "sharedBoard";
  allow create, update: if docId == "sharedBoard"
    && request.resource.data.keys().hasOnly(["payload", "updatedAt"])
    && request.resource.data.payload is string
    && request.resource.data.payload.size() < 900000;
  allow delete: if false;
}

如果既有規則本來就有允許所有路徑公開讀寫的萬用規則，以上限制會被其他規則的允許條件抵消；需先檢查既有規則。任何單一文件保存整套資料的方式較簡單，但多人同時編輯可能互相覆蓋，請避免同時在多台裝置修改。

模考與學測管理

可新增多次模擬考與正式學測，每個考試有自己的範圍與準備進度。

資料備份

匯出包含各科單元、百分比、課內細項、備註與讀書紀錄。建議每隔一段時間備份一次。

進度算法

科目總進度＝該科各單元百分比的平均；單次模考／正式學測進度＝該考試勾選範圍內各單元百分比的平均。這是方便視覺化的自評指標，不代表考試得分率。

每個單元都能直接更改百分比，也可以把內容拆成更小的細項；不必等整課完成才更新。

恢復初始範例資料

只在你想重新從預設資料開始時使用。這會刪除目前此瀏覽器儲存的看板資料，請先備份。
